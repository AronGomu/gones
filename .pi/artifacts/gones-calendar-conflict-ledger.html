Scope: static comparison of docs/tournament-inscription-calendar-architecture/00–09 against current Gones repo.

Decisions already fixed

  • Product: one Gones app; docs' “MTG Winds” name discarded.
  • Scope: all docs 00–09; full prod backend; organizer-updatable calendar.
  • Authority: current League + Live Tournament models win. New architecture wins for Calendar, Settings, Admin.
  • Delivery: hidden incremental vertical slices.
  • Done: prod-ready V1.
