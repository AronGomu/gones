Goal & success

Rebuild the Archive on three tiers — League → LeagueSeason → Tournament. Today's flat League becomes LeagueSeason; a new League tier groups Seasons; Tournament becomes top-level and may stand alone. leagues-archive → archive everywhere.

Success is observable, not asserted. Every line below is a check, not an opinion.
  • /archive/league-seasons lists one row per Season, expands one level to its Tournaments.
  • /archive/tournaments lists every Tournament, standalone ones included.
  • A Tournament with seasonId: null is creatable, listable, editable, deletable.
  • /global-stats?league=<id>&season=<id> serves ratings read from player_statistics, never replayed.
  • A Tournament older than 365 days refuses non-Admin writes with 409 archive_tournament_locked.
  • All public catalogs live in IndexedDB; localStorage keeps language, view preference, filters.
  • npm run test && npm run typecheck && npm run lint && npm run backend:test && npm run e2e:ci green.

Out

  • Data migration. All archive data is deleted; no users exist.
  • A League detail page. League is a column and a filter, never a route.
  • Multi-select scope. League and Season are each All-or-exactly-one.
  • Series/season auto-detection from event-name strings.
  • Live Tournament, Calendar/Event, Organization, auth surfaces.
  • Any change to /api/maintenance/player-names*.

The model

Tab 1 lists Seasons (one row each, League as a column, one expansion level to Tournaments). Tab 2 lists Tournaments. There is deliberately no League page. placeholder-league / "Unassigned Tournaments" is retired — seasonId: null replaces it.

Expand → migrate → contract

Why every commit still compiles. T2–T9 build the new /api/archive/** surface beside the old one. The legacy aggregate, endpoints, components and specs are deleted only at T19, when nothing calls them. No compatibility shim is ever written — old code merely survives until unused, so nothing is built to be thrown away.
Accepted consequence. Between T2 and T13 the archive is empty and the legacy pages render an empty list. That is expected, not a bug. It is only acceptable because Gones is unreleased, has no production environment and no users.

Where 25 000 comes from. Research measured mtgtop8's peak at roughly 17 500 tournaments in a single year, plus headroom. The earlier ×2 whole-archive figure of 180 000 predates year-partitioning and no longer applies — a cap now bounds one year, not the lifetime.

Read paths & caching

Season expand

years = [year(first) .. year(last)]

all cached && complete && locked
   → render from IndexedDB, no request
otherwise
   → GET .../league-seasons/{id}/tournaments
   → render, do NOT cache

Year freshness

cached && locked          → local, no request
cached && !locked && <24h → local, no request
cached && !locked && ≥24h → refetch the year
!cached                   → enqueue in backfill
The single-writer invariant. Only the backfill queue writes year partitions, and a partition is written and stamped completedAt in one IndexedDB transaction. A year is therefore atomically whole or absent — a crash mid-fetch leaves no record, never half of one. Read-through deliberately does not cache, which is precisely what preserves this.
Two databases, not one. gones-archive-local is the browser-authored authority (ADR 0028); gones-archive-cache is the public cache (ADR 0039). Mixing an authority with a cache in one database makes "purge the cache" unsafe.

Arbitration log

Nineteen writers inspected the codebase and overturned parts of the brief. Twenty rulings were issued; these are the ones that changed the plan rather than a detail.

R1The legacy table is league_archive_aggregates, not league_aggregates — renamed by 20260809122735_RenameLeagueArchiveTables.
R2The placeholder-league row cannot die at T1. InitialCreate re-seeds it, Delete refuses it, MigrationImportService calls SingleAsync on it, and seed-local.mjs throws without it — which would break npm run db:reset, the very command T1 mandates. It retires at T19.
R3Wire error codes follow the repo's existing snake_case, not the brief's camelCase: stale_version, not_found, validation_failed, plus new archive_tournament_locked and archive_league_not_empty. The browser-local mirror keeps camelCase — it is a local string, not a wire code.
R6Archive rows do not derive VersionedEntity. Load-bearing consequence: IncrementVersions only auto-bumps that base, so every archive write must increment version explicitly.
R11Three writers guessed three different repository method names. T12 owns the file and wins: listLeagues, listLeagueSeasons, listYears, listTournaments, listSeasonTournaments.
R13The IndexedDB allowlist is an exact array checked against a real directory walk, so it fills in two steps — naming a file before it exists turns the suite red.
R15The URL sort param becomes dir everywhere, including /global-stats which ships direction today. A user-visible URL change, accepted because there are no users. The wire parameter stays direction.
R17fixtures/league-domain/v1/ is a TypeScript↔C# parity corpus, not a bundle sample. It is re-pointed at the new shapes, not deleted — losing cross-stack parity proof was not an acceptable trade.
R20Live Tournaments validate leagueId against the archive aggregates. Dropping the legacy table forces re-pointing that reference in the same commit, or live seeding breaks.
R21Endpoint operation names are noun-first (ArchiveTournamentApplyEditBatch). The legacy ApplyArchiveTournamentEditBatch already exists and two endpoints sharing a WithName throws at startup.
R22T2's entities are renamed ArchiveLeague / ArchiveLeagueSeason / ArchiveTournament. T2 declared the bare names while T5, T6 and T7 were all written against the prefixed ones — every downstream read endpoint would have failed to compile.
R23T5 solely owns backend/src/Gones.Api/Archive/ArchiveResponses.cs. T5, T6 and T7 each declared ArchiveCatalogResponse<T>, and two of them declared ArchiveTournamentSummary — duplicate declarations are compile errors.
R24TournamentDate on the wire is a string, not a LocalDate. T6 and T7 declared the same record with different types; T6 wins on evidence — a LocalDate DTO member surfaces as an opaque interface in the generated client at gones-api.ts:10826.
R25DocumentVersion is int everywhere, matching the DDL's version integer. T3, T4, T6 and T7 had used long, which belongs to the VersionedEntity base the archive rows deliberately do not derive.
How these five were found. R1–R21 were issued while tickets were still being written, so only tickets authored after a ruling picked it up. R22–R25 came from a second sweep that actually diffed every producer's declared shape against every consumer's — and found four breaks the first pass had ruled on correctly but never propagated. Nine tickets now carry an arbitration override block (T2, T3, T4, T6, T7, T13, T14, T15, T19) which wins over the body beneath it.

Scope holes closed

A ticket writer caught two gaps that would otherwise have shipped broken. Both became tickets, and retiring the legacy surface moved from T17 to T19 as a result.
  • T17 — staged-edit UI. Nothing rebuilt ADR 0037's power-user staged-edit surface on /archive/**, so deleting the legacy editor would have left archive-staged-edit.cy.js without a subject.
  • T18 — browser-local union. Nothing joined the records T10 creates into either tab, silently breaking ADR 0028's dual-source rule.
