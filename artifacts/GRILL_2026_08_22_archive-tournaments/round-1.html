1. How does a Tournament with no League get stored?

This is the root decision — the API routes, the migration, the denormalized counts and the ratings rebuild all branch off it, and it is the one thing "establish correct data interfaces" cannot leave open.

2. What does the Tournaments tab list?

Decides whether a Tournament appears once or twice in the Archive, and whether the League tab's expand-row is a shortcut or the only way to reach a league's tournaments.

3. Row click: expand the league, or navigate to it?

Your brief says both — "click on the row to dropdown all related tournaments" and "clicking on a row directly go tournament|league". One row, one primary action; this picks which, and where the other one goes.

4. What is column 3 on the Tournaments tab?

Your column spec is written for a League row. "Number of tournaments" is meaningless on a Tournament row, so that slot needs a defined value or the two tabs need different column sets.

5. What exactly is "Date last update" in column 1?

The server stores updatedAt (last write to the row) and each Tournament carries tournamentDate (when it was played). They answer different questions and only one can be column 1's sort key.

6. How far does the leagues-archive → archive rename go?

ADR 0022 already did this rename once and deliberately froze the API paths while adding redirects for the UI routes. Doing it again has a defined blast radius per layer, and each layer costs differently.

7. Where do sorting, searching and paging happen?

You asked for "a paginated table like global rankings" — but global rankings ships both a server-paged endpoint and a whole-catalog endpoint the browser sorts itself. Which one "like global rankings" means changes the API surface this plan has to build.

8. What happens to the "Unassigned Tournaments" placeholder League?

Standalone tournaments are exactly what the placeholder League was invented to hold. Once tournaments can stand alone, keeping it means two representations of one idea.

9. How is the active tab represented in the URL?

Decides whether a tab is linkable and bookmarkable, what the breadcrumb says, and whether the two tabs are one component or two routed pages.

10. Do browser-local standalone Tournaments exist?

ADR 0028 makes the archive a merged union of server Leagues and browser-local ones. Whether that union extends to standalone Tournaments decides if the Tournaments tab needs a second IndexedDB store and a local- routing rule of its own.

11. What should the UI prototype deliverable be?

You named "UI prototypes for the refont of the archives main menu" as a key output. This decides what I actually build and where it lands.
