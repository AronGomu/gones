Feedback Calendar V1 — Round 3

Fifteen feedback lines. Nine are layout and ergonomics debt across the menu, header, calendar, dialogs, auth and account pages. Three build a file-driven local dev environment so a developer stops hand-creating test data. Three are architecture: signed-out Settings catalogs, a per-user offline read cache, and the rule that remote always erases local.

The four browser stores after this plan

StoreKindScopeRule
gones-liveIndexedDBbrowser-wideAuthority for anonymous + User running tournaments (ADR 0021). No sync.
gones-leaguesIndexedDBbrowser-wideAuthority for local- leagues (ADR 0028). Merged into the list, routed by id. No sync.
gones.settingslocalStoragebrowser-wideDeck archetypes + language. Replaced by the server catalog on sign-in (T14).
gones-cache newIndexedDBper userRead-only mirror of server responses. Overwritten on every success, purged on logout (ADR 0031).
Why exactly one store is user-scoped. Anonymous local data is meant to be shared by anyone using the browser — that is feedback #14’s first clause and what ADR 0021 and ADR 0028 already rely on. Cached private server data is the opposite: leaving user A’s leagues readable after user B signs in would be a data leak, so the cache keys on the user id and dies with the session. browser-local-scope.test.ts asserts both directions.

Assumptions worth arguing with

  • A2 — feedback #3 reverses round-2 A6. Day cells carry events again.
  • A3 — DBGONDB.json is not on this machine. The donor is gones-full-data.gones.json from the Drive snapshot; a trimmed derivative lands in the fixture and becomes the source of truth.
  • A4 — three environments ship (empty, minimal, demo). A fourth is a copied directory.
  • A9 — register adopts login’s social label, not the other way round.
  • A10 — complete-profile gets no return button; it is mid-OAuth.
  • A12 — “remote prevails” has exactly two surfaces: the cache row and the archetype catalog. Browser-local documents keep their local- ids and are never erased by signing in.
  • A13 — the read cache dies at logout. Offline convenience does not outrank not leaking one user’s data to the next.
