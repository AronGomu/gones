## Decisions taken while implementing

- **`data-cy` renames are scoped to the calendar feature's own screens.** Every `data-cy` rendered
  from `src/app/features/calendar/**` that carried the `tournament` token now carries `event`
  (`tournament-detail-*` → `event-detail-*`, `public-tournament-detail*` → `public-event-detail*`,
  `organizer-tournaments*` → `organizer-events*`, `deleted-tournaments*` → `deleted-events*`,
  `calendar-create-tournament` → `calendar-create-event`, and the dynamic `'tournament-' + slug`,
  `'tournament-row-' + id`, `'deleted-tournament-*-' + id`, `'tournament-format-option-' + id`,
  `'tournament-organization-option-' + id`, `'tournament-stale-change-' + i`). Element `id`s and the
  `aria-labelledby` / `for` targets that pair with them moved in the same edit. Nothing outside the
  feature moved: `admin-nav-deleted-tournaments`, `tournament-result-link`, `match-tournament`,
  `live-tournament-*` and `tournament-archive-*` are untouched.
- **CSS class names are NOT renamed.** `src/styles.css` still declares `.public-tournament-card`,
  `.public-tournament-detail`, `.tournament-management-*`, `.tournament-create-*`,
  `.tournament-request-*`, `.organizer-tournament-create` and `.calendar-create-tournament`; the
  templates keep referencing them. Renaming selectors is not in this ticket and would silently
  unstyle the pages.
- **i18n keys and their placeholders are NOT renamed** (T18 owns them). `tournamentManage.*` and
  `tournamentCreate.*` stay, and `participants.title` / `removeScope` / `removeBlockScope` /
  `blockScope` are still interpolated with a `tournament:` argument because the `en` and `fr`
  message strings still spell the placeholder `{tournament}`. Renaming the argument alone would have
  rendered a literal `{tournament}` in the UI.
- **Router paths are NOT renamed** (T18 owns them): `/calendar/tournaments/:slug`,
  `/organizer/tournaments*`, `/tournaments/new`, `/admin/tournaments/deleted`,
  `/tournament-requests/:token`.
- **Backend-owned literals stay as the server spells them**: the registration status
  `CancelledByTournament` and the `TournamentContentSanitizer` cross-reference comment in
  `server-sanitized-html.component.ts`.
- **The catalogue cache key value is unchanged** (`gones.calendar-v1.all-tournaments`); only the
  constant moved to `ALL_EVENTS_CACHE_KEY`. Changing the value would orphan every visitor's cached
  catalogue for no benefit.
- **Spec wiring moved with the specs**: `scripts/full-stack-ci.mjs`, `ops/acceptance-matrix.json`
  targets, `src/app/backend/server-authority-boundary.test.ts`'s server-read allowlist and two
  cross-reference comments.
