Goal

Land the whole feedback list: header and menubar polish, cookie-backed login persistence, a merged Settings + Account surface, structured geo profile fields, hard account deletion, a full-catalog calendar with one fuzzy filter, open tournament creation with signed-token approval, a role-scoped local Live store, a full-stack leagues-archive rename, and repo-wide data-cy coverage.

Done means: npm run test && npm run lint && npm run typecheck && npm run build && npm run backend:test && npm run cy:run green, and npm run acceptance:matrix still proved.

In scope

  • src/**, backend/**, cypress/e2e/**
  • docs/**, ops/acceptance-matrix.json, scripts/**, package.json
  • 6 ADRs (docs/adr/0021…0026) + 3 architecture HTML docs

Out of scope

  • Deployment topology, Docker / compose, Brevo provider config
  • New OAuth providers
  • Any new private migration-bundle producer — the one-way door of ADR 0020 stands
  • Retiring the Leagues archive; it is renamed, not removed

Ordering constraints that are not negotiable

  • T1 first. It is the only ticket with human-blocking steps (npm install) and it installs the conventions every later ticket writes against.
  • T5 and T7 before T8. The account page is a literal move; moving it before the schema and the sessions removal settle means doing it twice.
  • T12 → T13 → T14. Endpoint, then modules with their own tests, then the page. Each layer ships behind the previous one's tests.
  • T23 → T24, back to back. Regenerating the client renames the operation methods; the frontend does not compile in between. Do not interleave another ticket there.
  • T25 last. Sweeping identifiers into components that later tickets rewrite is wasted work.
Two tests will bite anyone who skips the Inputs section. src/app/backend/server-authority-boundary.test.ts pins the exact list of files allowed to touch localStorage / indexedDB — T13, T20 and T21 each add one and must say why in that file. And T1's coverage test asserts every allowlist path still exists, so deleting or renaming a component (T7, T24) means editing the allowlist in the same commit.
