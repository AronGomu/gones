# Use Angular Material for UI Components

Gones is migrating to Angular and needs a stable component foundation for forms, dialogs, tables, navigation, and accessible interaction states. We decided to fully embrace Angular Material for standard UI components while keeping the Gones dark metal, blood-red, rust, and card-game-inspired color scheme as closely as possible through theming and custom brand styling, accepting that some of the current bespoke visual character may become more Material-shaped.
