# Use Public Read with Google OAuth Role Allowlist

Gones data should be publicly readable and downloadable, while only trusted organizers can modify source data and manage access. We decided Visitors can read without signing in, Google OAuth is used only for Organizer/Admin access, and roles are granted by a lowercase authorized-email list stored in Supabase rather than hard-coded in the codebase. Unknown Google-authenticated users receive no extra permissions and behave like Visitors. The first Admin User will be bootstrapped through setup SQL/seed data rather than app code or a runtime Edge Function. Supabase Row Level Security policies enforce public read, Organizer/Admin writes, and Admin-only role management; Angular UI hiding is not treated as the security boundary. We will avoid Supabase Edge Functions for MVP unless a permission rule cannot be expressed with SQL/RLS.
