# Use Neutral Match Source Shape with Import Adapters

Gones imports match rows from source formats that describe a result from one player's perspective, but the domain model treats a Match as neutral source data between two Player Names. We decided the Angular/Supabase canonical Match shape will use neutral fields such as `table`, `player1Name`, `player2Name`, `player1Score`, `player2Score`, `player1DeckArchetype`, and `player2DeckArchetype`, while Round Import adapters convert source-format fields such as `table`, `player`, `result`, `opponent`, `player_decklist`, and `opponent_decklist` into that shape. Legacy import headers named `player_decklist` and `opponent_decklist` contain Deck Archetype data, not full Decklists. Adapter tests must cover real/current import examples, won/lost/draw score conversion, invalid rows, quoted names, and Deck Archetype preservation so the conversion boundary is explicit and non-lossy.
