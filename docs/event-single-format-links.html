Exactly one format

Domain + API require exactly one. Unique event_formats(event_id) index enforces max one; supported domain writes guarantee required row. Any active catalog format accepted. Referenced format cannot be deleted. Legacy no longer mandatory.

Server-owned display

Persist base title. Backend derives {Format} — {Title}. Frontend never rebuilds domain display text.

Simple links

/app/path, http://, https://. No FK, existence probe, sync, or lifecycle coupling. Broken dest valid.

Unreleased reset

Local multi-format rows may block unique index. Reset DB. Fixtures split per format; registrations stay first catalog child.
