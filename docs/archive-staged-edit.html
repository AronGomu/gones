Architecture · Proposed ADR 0037

Staged Archive Tournament Edit

Read-only by default. Draft stays in memory. Save emits named intents once. Authority commits atomically or writes nothing.

User transaction

Readauthoritative doc
→
Editclone to memory
→
Confirmmove + deletion summary
→
Saveone versioned batch

Batch contents

StagedSeparate
name, date, same-authority League move, add/delete/replace Rounds, Round Entries/import output, archetypeswhole Tournament delete, whole League delete

Authority execution

Server

  1. Load source/target deterministic order
  2. Check both versions
  3. Apply explicit intents in memory
  4. One Apply per aggregate
  5. One EF transaction + save

Local

  1. Open one IndexedDB readwrite tx
  2. Read source/target
  3. Check both versions
  4. Transform + put both
  5. Commit only on complete

Stale version

412 keeps draft byte-for-byte. UI shows conflict + Reload Latest. Discard needs confirmation. No merge, rebase, retry, local shadow, or partial save.

Hard boundaries

  • No whole-document save request.
  • No local↔server move.
  • No sync.
  • No repository calls while drafting.
  • Round/entry deletions get one final summary prompt.
  • One version bump per changed aggregate.

Refs: ADR 0010, ADR 0028, proposed ADR 0037.
