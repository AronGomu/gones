Rules

Identitytrim only; case-sensitive. Alice ≠ alice.
Eligibility≥1 valid head-to-head Match. Bye-only excluded.
Authorityserver completed Leagues only. Active/local/deleted excluded.
Default sortMatch Wins ↓, Game Wins ↓, Match Draws ↓, name ↑.
Explicit sortnumeric col asc/desc; name ↑ tie. Null rates last.
Pagination100 default; 10/25/50/100. Position is current search-result sorted index.

Metric notes

  • Match win rate = Match wins / played Matches. Draws are non-wins.
  • Games cannot draw in this source. Games Played = Game Wins + Game Losses.
  • Nemesis = opponent causing most losses. Rival = opponent met most. Alpha tie.
  • Most-played archetype counts Matches, using Match field then Tournament roster fallback.
  • No Elo in this release.
