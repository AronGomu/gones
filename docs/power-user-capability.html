Architecture · Proposed ADR 0037

Power User Capability

Browser preference reveals advanced mutation workflows. It never grants server authority, changes adapter selection, or hides browse destinations.

Three independent gates

1 · Browser preferencegones.settings.power-user
signed in/out
default false
2 · Server roleOrganizer/Admin for server mutation
backend policy remains final
3 · Document originlocal- → browser
other ID → server
no sync
mutation allowed = Power User enabled AND authority permits document/action

Mode-off behavior

Still available
  • Home cards
  • Calendar/League/Live browse
  • Results + Player/Global stats
  • League/full export
  • Event registration
  • Settings
Blocked
  • Event create/edit/publish UI
  • League/Archive create/edit/move/import/restore/delete
  • Live create/settings/player/round/finalize/delete
  • Direct create routes
