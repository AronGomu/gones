Organization Membership Model

Organizations and organizers form a many-to-many graph, and that graph is the only source of truth for the Organizer global role. An organization with no member is not an error — it is Draft, and Draft organizations cannot publish events.

The two sides

table organizations

Soft-deleted through deleted_at; IsActive => DeletedAt is null. Deletion is reversible via the admin restore endpoint. An organization's roster lives in organization_members.

table organization_members

One row per (organization, user) pair with an organization role: Owner or Organizer. This table decides the account-wide global_role.

derived Draft

Zero members. Never stored — computed as memberCount == 0 and surfaced as isDraft on the admin organization response.

Organization lifecycle

create org (no members) ─→ Draft · editable · restorable · cannot publish
add first member ─→ Active · publishes events · member promoted to Organizer
remove last member ─→ back to Draft · 204, no conflict · member demoted to User
delete org ─→ soft-deleted · future events hidden · past events + registrations kept
restore org ─→ previous state, Draft or Active depending on the roster
Why no 409 on the last removal. Blocking the removal forces an admin to delete a whole organization just to remove a person from it. Draft is the honest state: the record exists, it simply cannot act until someone staffs it. Publishing is where the invariant is enforced — 409 organization_is_draft.

One shot, never recurring. The heal runs inside a single EF migration. A scheduled job would eventually archive a Draft organization created deliberately minutes earlier.

Admin surface

/admin/organizations is the single screen for both sides of the graph: organizations with create on the left, the selected organization's roster on the right — member chips plus a user picker. The picker fetches users once and filters client-side, capped at 500 accounts with a visible warning past that point; server-side search is deliberately deferred until the cap is reached.

The users screen no longer grants the Organizer role by hand. There is exactly one way to become an organizer: be a member of an organization.
