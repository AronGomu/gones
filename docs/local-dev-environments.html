Local Development Environments

A dataset is a directory of JSON files. npm run dev with no flag still gives an empty app; --env=<name> resets the database and replays that directory through the real HTTP API. Editing test data is editing a text file.

Layout on disk

fixtures/dev-environments/<name>/
  environment.json        required   { name, description, resetDatabase }
  accounts.json           optional   [{ email, username, firstName, lastName, role, password?, emailConfirmed? }]
  organizations.json      optional   [{ key, name, description, website, contactEmail, ownerEmail }]
  formats.json            optional   [{ key, name, slug, sortOrder }]
  tournaments.json        optional   [{ key, organizationKey, organizerEmail, title, …, startsAtLocalOffsetDays, formatKeys }]
  registrations.json      optional   [{ tournamentKey, userEmail }]
  archive-leagues.json        optional   [{ id, name, createdAt }]
  archive-league-seasons.json optional   [{ id, name, leagueId, status }]
  archive-tournaments.json    optional   [{ id, name, seasonId, tournamentDate, status, rounds, playerArchetypes }]
  live-tournaments.json   optional   [{ key, organizerEmail, players, roundCount, scoredRounds, leaveRoundOpen, leagueKey }]

A missing optional file means an empty list. environment.json.name must equal the directory name. Fixtures cross-reference each other by human-readable key — never by GUID, because no GUID exists before the seed runs.

Adding an environment is copying a directory, editing environment.json.name to match it, and running npm run dev -- --env=<name>. No code change, no rebuild.

What a run does

1 · npm run dev -- --env=demo → parseDevArgs pulls --env out of the ng serve arguments
2 · docker compose up -d --wait postgres migrator api worker → wait for /health/ready
3 · scripts/seed-dev-accounts.mjs — the two fixed ADR 0029 accounts
4 · scripts/seed-dev-environment.mjs --env=demo → validateEnvironment → any problem stops here, exit 2
5 · resetDatabase: true → scripts/reset-local-stack.mjs (down --volumes → up --wait → migrator seed)
6 · accounts: POST /api/auth/register, then SQL for email_confirmed + global_role
7 · loginAll() → one access token per verified fixture account
8 · formats → organizations → tournaments (preview + publish) → registrations
9 · archive (POST /api/archive/restore-full) → running tournaments (create · players · rounds · scores · validate)
10 · summary printed → ng serve --host 127.0.0.1

Two rules that keep it honest

API Seeding is not SQL

Every row is created through the endpoint the browser uses. A fixture the app would refuse cannot reach the database. The single exception is email_confirmed / global_role, which have no endpoint — the same exception ADR 0029 already made.

reset A dataset never stacks

Any environment carrying data sets resetDatabase: true and wipes the volume first. Swapping demo → minimal leaves nothing of demo behind. validateEnvironment rejects resetDatabase: false together with data.

Dates

Calendar fixtures declare startsAtLocalOffsetDays — a signed integer against today — so a dataset committed once still shows past, ongoing and upcoming tournaments a year later. The demo spread is -90, -45, -21, -7, 0, +3, +10, +24, +60.

League Archive fixtures keep absolute tournamentDate values. An archive is history, and a rolling history would be a lie.

Validation is a committed gate

ops/dev-environments.test.ts runs inside npm run test and calls validateEnvironment on every shipped environment. It checks shape, role vocabulary, password policy, unique keys and every cross-reference: a tournament's organization and formats, a registration's tournament and user, a running tournament's league and organizer, and that a running tournament cannot score more rounds than it declares.

A broken fixture fails in CI, not thirty seconds into a Docker reset. That is the point of validating the directory rather than trusting the seeder to crash usefully.

What this is not

  • Not shipped. fixtures/ is in no image and no release path reads it.
  • Not a migration path. the archive fixtures are a trimmed derivative of a real export; ADR 0020's one-way door on migration bundles is untouched.
  • Not usable without Docker. --env with --no-docker is refused explicitly.
